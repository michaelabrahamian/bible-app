# Getting started

See [README.md](README.md) for the current Node version, installation, development commands, and validation steps.

The app bundles the public KJV and partial `ArmEastern.json` downloads. Armenian coverage is limited to Genesis, Exodus, and the four Gospels; entirely empty chapters are hidden and 17 partly populated chapters with unreliable references are withheld. Comparison mode explains missing or withheld text. See [data/README.md](data/README.md) before using it for distribution.
