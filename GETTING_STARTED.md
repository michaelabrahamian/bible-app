# Getting started

See [README.md](README.md) for the current Node version, installation, development commands, and validation steps.

The app bundles the public KJV and partial `ArmEastern.json` downloads. Armenian coverage is limited to Genesis, Exodus, and the four Gospels; empty placeholders are hidden in the reader. See [data/README.md](data/README.md) before using it for distribution.
